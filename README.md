# ELAN TECH — AI Ассистент по стилю

Pet-проект: веб-приложение для персонализированного подбора одежды. Пользователь заполняет анкету и получает 10 вариантов образов с изображениями и описаниями, затем сохраняет понравившиеся варианты в избранное.

## Возможности

- Регистрация, вход и личный кабинет.
- Анкета: параметры фигуры и внешности, мероприятие, палитра и пожелания.
- Подготовка стилистического описания по программным правилам.
- Генерация изображений через Cloudflare Workers AI.
- Просмотр образов и управление избранным.
- Восстановление пароля по коду из письма при настроенном SMTP.

## Стек

Python 3.11+, Flask, SQLite, HTML, CSS, JavaScript, Pillow, matplotlib. По умолчанию используется FLUX.1-schnell через Cloudflare Workers AI; модель задаётся настройками окружения.

## Как работает персонализация

Анкета → серверная проверка → стилистические правила → отдельный промпт для каждого варианта → Cloudflare Workers AI → сохранение изображений и описаний → личный кабинет.

Собственная нейросеть не обучается. Анализ анкеты и описания карточек формирует приложение, а внешняя модель создаёт изображения.
