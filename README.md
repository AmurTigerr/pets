# ELAN TECH — AI Ассистент по стилю

Pet-проект: веб-приложение для персонализированного подбора одежды. Пользователь заполняет анкету и получает 10 вариантов образов с изображениями и описаниями, затем сохраняет понравившиеся варианты в избранное.

## Возможности

- Регистрация, вход и личный кабинет.
- Анкета: параметры фигуры и внешности, мероприятие, палитра и пожелания.
- Подготовка стилистического описания по программным правилам.
- Генерация изображений через Cloudflare Workers AI.
- Просмотр образов и управление избранным.
- Восстановление пароля по коду из письма при настроенном SMTP.

## Стек

Python 3.11+, Flask, SQLite, HTML, CSS, JavaScript, Pillow, matplotlib. По умолчанию используется FLUX.1-schnell через Cloudflare Workers AI; модель задаётся настройками окружения.

## Как работает персонализация

Анкета → серверная проверка → стилистические правила → отдельный промпт для каждого варианта → Cloudflare Workers AI → сохранение изображений и описаний → личный кабинет.

Собственная нейросеть не обучается. Анализ анкеты и описания карточек формирует приложение, а внешняя модель создаёт изображения.

## Локальный запуск

Выполните команды в каталоге проекта (macOS/Linux):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните в `.env`:

```dotenv
CLOUDFLARE_API_TOKEN=your_token
CLOUDFLARE_ACCOUNT_ID=your_account_id
CLOUDFLARE_IMAGE_MODEL=@cf/black-forest-labs/flux-1-schnell
```

Для отправки писем дополнительно задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM`. Поддерживаются `SMTP_USE_TLS` и `SMTP_USE_SSL`.

Секрет Flask задайте в окружении процесса до запуска:

```bash
export STYLE_SENSE_SECRET="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
python3 app.py
```

В текущей версии секрет читается до загрузки `.env`, поэтому для него используется `export`. Команда создаёт новый секрет; для постоянного развёртывания используйте сохранённый уникальный секрет.

Откройте http://127.0.0.1:5000/. База SQLite и каталог изображений создаются автоматически. Для генерации нужны действующие реквизиты Cloudflare и доступная квота сервиса.

## Структура

```text
app.py                Сервер, маршруты, база и интеграция генерации
templates/            Актуальные HTML-шаблоны Flask
styles.css            Стили
script.js             Клиентская логика
requirements.txt      Зависимости
.env.example          Пример настроек без секретов
```

Главная страница приложения — `templates/index.html`. Корневые `index.html` и `cabinet.html` — ранние статические версии; для актуального интерфейса запускайте Flask.

## Ограничения и статус

Это учебный прототип. Изображения могут содержать визуальные ошибки, отклонения от палитры и повторяющиеся решения. Результат не является точной виртуальной примеркой или каталогом доступных товаров.

В текущей версии новая генерация заменяет предыдущую подборку и очищает связанное избранное. Генерация выполняется последовательно и зависит от доступности внешнего API.

Перед публичной эксплуатацией необходимо закрыть доступ к служебным файлам (сейчас статический каталог указывает на корень проекта), убрать возврат кода восстановления при ошибке SMTP, настроить HTTPS и производственный WSGI-сервер вместо отладочного запуска, проверить права доступа к изображениям и оформить обработку персональных данных под реальные условия размещения.
